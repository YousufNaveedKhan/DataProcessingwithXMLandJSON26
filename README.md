# Data Processing with XML and JSON

Teaching material for the Semester 2 module **Data Processing with XML and JSON**: example files for classroom practicals and assignments for students.

## Folder layout

Every lecture has its own folder:

```
LectureNN-Topic-Name/
├── practical/       example files used in class
└── ASSIGNMENT.md    assignment shared with students
```

## What you need

- **VS Code** (with an XML extension, e.g. *XML* by Red Hat)
- **Chrome** or **Edge** to open files and see parser errors
- Semester 1 background: HTML, CSS, basic JavaScript, Git and GitHub

## Working with the files

- Open the repo folder in VS Code.
- Open `.xml` files in the browser (right-click, "Open with", or drag and drop onto Chrome).
- Save all files as **UTF-8**.
- On Windows keep **File name extensions** visible, otherwise `file.xml` can silently become `file.xml.txt`.
